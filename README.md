# shiboqi-for-c8t6 —— 便携三相电测试仪 / 三相电示波器

**MCU**: STM32F103C8T6 (LQFP48, 72MHz) · **显示**: 0.96" SSD1306 128×64 I2C · **输入**: 4 按键
**被测对象**: 三相三线电调（ESC）输出 —— 基波 **300~800 Hz**，PWM 载波 **24 kHz**

---

## 0. 先说清楚：本工程与"实施方案"的三处必要差异

实施方案是按**工频（50 Hz）**写的，而本项目已确认的硬件规格是**电调输出**。
电气与采样参数按已确认的硬件重做，架构（双模式、4 键语义、版面/刷新策略、宿主测试纪律）保留。

| 项 | 实施方案原值 | 本工程实际值 | 为什么必须改 |
|---|---|---|---|
| 被测基波 | 45~65 Hz（§8 待确认） | **300~800 Hz** | 已确认是电调输出 |
| PWM 载波 | 未涉及 | **24 kHz**，且要求**看清载波** | 采样率必须按载波定，不是按工频 |
| TIM3 触发率 | `ARR=5624` → 12800 Hz | **240 kHz / 720 kHz（载波视图）**、**48 kHz（基波视图）** | 12800 Hz 对 24 kHz 载波的 Nyquist 仅 6.4 kHz，**看不到载波** |
| 帧长含义 | "256 点 = 恰好一个 50 Hz 周期" | 256 点 = **1.067 ms（载波视图）** / **10.67 ms（基波视图）** | 时窗按载波周期与基波周期分别校核 |
| 输入前端 | 假设 0~300 V AC 分压 | **无隔离、交流耦合、1.65 V 偏置、分压 1/13.05** | 见 `THREE_PHASE_HW_DESIGN.md` |
| 满量程 | — | **±21.5 V**（输入侧峰值） | 电调母线 24 V 上限，瞬时峰值 2·Vbus/3 = 16 V |
| 直流母线测量 | 方案询问是否需要 | **不需要**（用户已确认） | 交流耦合只测交流，天然匹配 |

其余（I2C2+DMA 刷新、丢帧不排队、波形页裁到波形带、事件当拍刷新、宿主测试逐像素校验）
**完全按实施方案执行**。

## 1. 采样率设计：为什么是这几个数

抽取用**整数均值（boxcar）**，其频响零点在 `k·fs/N`。要让零点**精确压住 24 kHz 载波及其谐波**，
必须满足 `fs / N = 24000`，即**触发率必须是 24 kHz 的整数倍**：

| 模式 | 时基 | 触发率 | ARR | 抽取 | 有效采样率 | 每 24 kHz 载波周期点数 |
|---|---|---|---|---|---|---|
| 三相 | 载波视图 | **240.0 kHz** (=24k×10) | 299 | 1 | 240 kSPS | **10** |
| 三相 | 基波视图 | **48.0 kHz** (=24k×2) | 1499 | 2 | 24 kSPS | — (载波被零点压掉) |
| 单路 | 载波视图 | **720.0 kHz** (=24k×30) | 99 | 1 | 720 kSPS | **30** |
| 单路 | 基波视图 | **48.0 kHz** | 1499 | 2 | 24 kSPS | — |

**为什么基波视图不直接采 24 kHz**：Nyquist 恰好等于载波频率是最坏情况，载波会混叠成
直流/低频假信号污染相位测量。多采一倍再平均（N=2）让零点落在 24k/48k 上，才干净。

**占空比校核**（Ts=1.5 → 14 个 ADCCLK @12 MHz = 1.1667 µs/通道）：

| 情形 | 单次扫描耗时 | 触发周期 | 占空比 |
|---|---|---|---|
| 三相 240 kHz | 3×1.1667 = 3.50 µs | 4.167 µs | **84%** |
| 单路 720 kHz | 1.1667 µs | 1.389 µs | **84%** |
| 基波 48 kHz 三相 | 3.50 µs | 20.83 µs | 17% |

最紧的是 **84%**，留 16% 余量；因为是循环 DMA，CPU 不参与逐次转换。

**ADCCLK = 12 MHz**：F103 上限 14 MHz，APB2=72 MHz 时 `/4=18 MHz 超限`，
**必须用 `/6=12 MHz`**。`adc.c` 里显式 `__HAL_RCC_ADC_CONFIG(RCC_ADCPCLK2_DIV6)` 覆盖，
并且 `ADC_SelfCheck()` 会回读验证 —— CubeMX 的 `.ioc` 里 `ADCFreqValue=36000000` 是非法的。

## 2. 引脚分配（LQFP48）

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| UA / UB / UC 输入 | **PA0 / PA1 / PA2** | ADC1_IN0/1/2 | 模拟输入，源阻抗约 520 Ω |
| K1 `MODE` | **PB0** | GPIO 输入上拉，低有效 | 短按切子视图 / 长按切模式 |
| K2 `CH/SEL` | **PB1** | 同上 | 短按选通道 / 长按连发 |
| K3 `RANGE/ADJ` | **PB5** | 同上 | 短按移焦点 / 长按进出编辑态 |
| K4 `OK/BACK` | **PB6** | 同上 | 编辑态加档 / 非编辑态冻结 |
| OLED SCL / SDA | **PB10 / PB11** | I2C2 @400 kHz | SSD1306，地址 **0x78（写）= 7 位 0x3C** |
| 采样触发 | 无引脚 | **TIM3 TRGO** → ADC1 外部触发 | 只用 TRGO，**不占通道** |
| 控制节拍 | 无引脚 | **TIM4** 更新中断 1 kHz | |
| 状态灯 | **PC13** | GPIO 推挽，低有效 | 有帧在跑时每 500 ms 翻转 |
| 调试 | PA13 / PA14 | SWD | |
| 晶振 | PD0 / PD1 | 8 MHz HSE | |

### 引脚冲突说明（重要）

PB0/PB1 在 LQFP48 上**同时是 TIM3_CH3/CH4 的复用脚**。本工程把 TIM3 只用于产生
**TRGO**（`MasterOutputTrigger = TIM_TRGO_UPDATE`），**不配置任何输出通道**
（不设 `CCER`/`CCMR` 输出位），因此 PB0/PB1 保持 GPIO 功能，做按键**不冲突**。

### DMA 固定映射（RM0008 表 78，不可自由选择）

| DMA | 用途 |
|---|---|
| **DMA1_Channel1** | ADC1 扫描结果 → 双缓冲 |
| **DMA1_Channel4** | I2C2_TX（OLED 异步刷新） |

## 3. 按键语义（"一个键一个稳定语义"）

| 键 | 短按 | 长按（≥700 ms） | REPEAT（长按后） |
|---|---|---|---|
| **K1 `MODE`** | 切子视图（三相：数值↔波形；单路：波形↔仪表） | **切模式**（三相↔单路）；**编辑态下 = 取消编辑** | 不参与 |
| **K2 `CH/SEL`** | 选中下一个通道（三相 UA→UB→UC→ALL；单路 A→B→C） | 进入连发 | 连续步进通道 |
| **K3 `RANGE/ADJ`** | 循环移动调整焦点（量程→时基→触发电平→触发方式） | **进入/退出编辑态** | 不参与 |
| **K4 `OK/BACK`** | 编辑态 = 焦点值 +1 档；非编辑态 = **冻结/解冻** | 编辑态 = 退出编辑；非编辑态 = **复位视图** | 编辑态连续加档 |

### 防误触（四层，都在 `app_mode.c` 落地）

1. **时间**：700 ms 长按门槛，远高于 20 ms 机械消抖；
2. **上下文**：编辑态下长按 K1 = 取消编辑，**不切模式**；
3. **提交时机**：`BTN_EVENT_LONG` **只在松手沿产生** → 按住不放不会反复切换；中途松手得到 SHORT，天然完全取消、无副作用；
4. **视觉**：长按期间显示 `SWITCH?`/`SWITCH!` 提示，达阈值前不改任何状态。

## 4. 版面

**三相 · 数值页**
```
y= 0..11  3PH        400.00Hz        ABC     ← 状态行(左模式/中频率/右相序或ERR)
y=12      ──────────────────────────────
y=14..37  11.3V                    V  UA   ← 焦点通道 24px 大字
y=40      ──────────────────────────────
y=41..52  UB 11.31V      UC 11.31V            ← 另两相 + 相角(下一行)
y=53..63  U0.1%      CAR        K1 M      ← 不平衡度 / 时基 / 按键提示
```

**三相 · 波形页**：状态行 + 波形带（y=13..52，3 条轨迹共时间轴 + 分格虚线 + 通道标记 + 量程）+ 底行
**单路 · 波形页**：波形带放大给单通道，叠加**触发电平虚线**
**单路 · 仪表页**：Vrms 大字 + Vpp / 频率

**刷新策略**（对应实施方案 §5.2）
- **双缓冲 + 差分刷新**：每帧从空白重画，KK_OLED 只发脏页；
- **局部裁剪**：波形绘制限制在波形带内（`OLED_SetClipWindow`），脏页稳定在 1~2 页；
- **异步发送**：`OLED_UpdateDMA()`；`OLED_IsBusy()` 为真则**丢弃本帧**（不排队），UI 延迟有界；
- **三档节拍**：波形页 33 ms（30fps）/ 数值页 100 ms（10Hz）/ 按键事件当拍。

**刷新率预算**：I2C 400 kHz 下全屏 ≈1030 B ≈ 23 ms；差分只波形带 2 页 ≈256 B ≈ 6 ms。
因此波形页 30fps 时 I2C 占用约 18%，且因为是 DMA 异步**不阻塞**主循环与测量。

## 6. 待上板确认（会影响正确性或显示，无法在宿主机验证）

1. **OLED 列偏移是 0 还是 2**：132 列屏需偏移 2。用满屏 0xFF 测试图案判定。
   地址已确认 **0x78（写）/ 7 位 0x3C**。
2. **运放 `LRA8552A-D` 引脚号**：`THREE_PHASE_HW_DESIGN.md` §16.1 按通用 SOP-8 写出，
   **未逐脚核对数据手册**；若引脚不同只需换引脚号，拓扑不变。
3. **SOT23-5 的 24C02 引脚号各厂不一致**，接线前查实物手册（标定存储功能目前未启用）。
4. **帧计数是否持续增长**：状态灯每 500 ms 翻转即说明 `TIM3→ADC→DMA→抽取` 通路在跑，
   而不是"屏幕有数但全是初值"。
5. **三相输入只接 3 根线**：电调浮空，**不要接 DC−、不要接地夹、不要再引入第二个地参考**
   （会破坏虚拟中性点，见硬件文档 §2 ①）。

## 8. 与上一版接口的差异（给后续维护者）

- `Buttons_Poll` **语义强化**：松手沿的 SHORT/LONG **优先于**队列里的 REPEAT
  （否则"按住 1 s"时 LONG 会被 REPEAT 挤掉）。见 `buttons.c:buttons_emit`。
- `Measure_Frame` 的 RMS/最值改为**在整数个基波周期窗口内统计**（`meas_cycle_window`）
  —— 否则 256 点对 400 Hz 只有 4.27 个周期，残段会让三路 RMS 差 3%。
- 相位差符号约定：过零点**更晚 = 滞后 = 负角度**。
